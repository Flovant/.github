# Flovant

Студия разработки из Санкт-Петербурга. Делаем сайты и интернет-магазины, телеграм-ботов, личные кабинеты с CRM, небольшие приложения и игры. Берём на себя дизайн, разработку и запуск, а когда проекту нужна онлайн-оплата или учёт заявок, подключаем их к сайту.

Работаем с заказчиками по всей России, удалённо. Первый экран сайта показываем бесплатно, до сметы. ТЗ и цену фиксируем письменно до начала работ, платить просим только за принятые этапы. Домен, хостинг, код и доступы после запуска остаются у заказчика.

Кейсы с описанием, как устроен каждый проект, лежат в репозитории [portfolio](https://github.com/Flovant/portfolio), а открытые цены на [flovant.ru](https://flovant.ru). В этой организации выкладываем то, что можно показать вместе с кодом: сервисы на Java и PostgreSQL, проверки выгрузок 1С и банка, настольные приложения на Go.
